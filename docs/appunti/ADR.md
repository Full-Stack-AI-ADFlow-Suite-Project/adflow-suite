# Decisioni · AdFlow Suite

Il registro unico delle decisioni: una riga per decisione, con il perché e le alternative scartate. Una decisione nuova è una riga nuova; quella che cambia scende in fondo, tra le sostituite. Fino al 06/10/2026 le motivazioni stavano in due tabelle delle note, con una numerazione a parte (D-01…D-52 nel flusso, D-A…D-C14 nell'architettura): sono confluite qui, e la colonna **Alias** tiene quei numeri perché i rimandi nei documenti e nelle pagine restino validi. Dove il perché manca, la decisione era stata registrata senza motivazione; il testo originale completo di ogni ADR è nella storia di git (il vecchio file ADR.md che stava in docs/, fino al 30/09/2026).
