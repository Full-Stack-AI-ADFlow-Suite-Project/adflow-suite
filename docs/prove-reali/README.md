## Come si usa

1. **Un titolare reale per profilo.** Tutte le 25 foto di un profilo vengono dalla stessa persona: è questo che rende il gruppo omogeneo (stesso telefono, stesso locale, stesse abitudini).
2. **Foto già scattate, non rifatte.** I difetti veri sono il motivo della richiesta. La lista è un obiettivo: se una foto manca, va bene una simile dello stesso titolare. Annota la sostituzione.
3. **Consenso scritto.** Le foto servono solo per prove interne: non si pubblicano e si cancellano su richiesta. Clienti riconoscibili, minori e targhe vanno oscurati o esclusi.
4. **Le foto non entrano nel repo.** Salvale fuori, per esempio in `prove-reali/<NN-attivita>/<NN>.jpg`, con il numero della riga della tabella.
5. **Il testo "Come si presenta oggi"** contiene apposta maiuscole, errori e punteggiatura approssimativa. Serve a provare la riscrittura dei testi. Se il titolare reale ha un suo testo, usa quello.

## Legenda dei difetti

| Termine | Che cosa significa |
|---|---|
| scura / sovraesposta | poca luce o luce bruciata |
| controluce | finestra o vetrina dietro il soggetto |
| flash | flash diretto, riflesso o ombra dura |
| luce mista | neon e luce calda insieme, colori falsati |
| mossa / sfocata | soggetto o mano in movimento, fuoco sbagliato |
| sbilenca | orizzonte o linee verticali storte |
| lontana / decentrata | soggetto piccolo o fuori centro, ritaglio difficile |
| disordine | sfondo con oggetti estranei (attrezzi, sacchi, cavi, persone) |
| riflessi | vetro, plastica, metallo, bottiglie |
| verticale / orizzontale | formato scomodo per l'uso previsto |
| zoom | zoom digitale, grana forte |
| compressa | passata da WhatsApp o scaricata dai social, bassa qualità |
| testo | cartelli, etichette o scritte da leggere o da evitare |
| persone | volti di clienti o passanti da escludere o oscurare |
| screenshot | schermata o foto di una foto |
| buona | foto già discreta: serve a vedere che l'app non la peggiori |

Ogni profilo mescola foto di prodotto, lavorazione, ambiente, persone, cartelli e offerte, più qualche caso limite.
