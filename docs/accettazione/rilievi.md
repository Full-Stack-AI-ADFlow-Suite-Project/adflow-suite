# Registro dei rilievi

Simulazione di accettazione dell'MVP (ADR-120, corsia 10). Ogni task T4-1xx aggiunge le sue righe; nessuno cancella le righe degli altri. Il formato è quello di `docs/accettazione-post-mvp.md` §1.2.

**Gravità**: Alta (bloccherebbe la produzione), Media (va risolta prima dello sviluppo completo), Bassa (si pianifica).
**Esito**: `confermato`, `smentito` (l'ipotesi di §3 non regge), `non provato` (con il motivo).
**Classe** (assegnata in T4-108): `correggere`, `limite MVP`, `roadmap`, `proposta`.
